功能

该有的都有，多余的都没有

不做全家桶，不驻留服务，不偷偷开机自启。八项能力，覆盖从卸载到清理的每一步。

静默卸载

直接调用注册表里的静默卸载参数，MSI、NSIS、Inno 自动识别，不再弹出软件自带的卸载向导。

残留扫描

卸载后继续排查安装目录、AppData 与 ProgramData 同名文件夹、开始菜单与桌面快捷方式、注册表遗留项。

强制删除

卸载程序坏了、卡住或根本不存在？跳过它，直接扫描并清理，再把它从程序列表里彻底移除。

占用处理

清理前检测占用待删文件的进程，可以随手结束；仍然删不掉的，一键登记为「重启后自动删除」。

Store 应用管理

Microsoft Store 装的应用也能在这里看到图标、体积和发行商，用同一套界面卸载，不必再翻设置。

启动项管理

汇总 Run / RunOnce 与启动文件夹里的自启项，禁用或直接删除，开机慢的时候知道该关谁。

真实体积

注册表没写体积就后台并行补算并缓存，第二次打开秒出数字，按体积排序先删最占地方的。

HTML 报告

一键导出全部已安装程序与清理记录，单个 HTML 文件，换机备份、团队交接或排查问题时直接发出去。

流程

三步，一条直线

没有设置向导，不用注册登录。打开就能卸，卸完还能看清理了什么。

  1. 01

    选中程序

    列表按体积排序，双击或按 Enter 直接进入卸载；新装与改动过的程序会高亮标出来。

  2. 02

    扫描残留

    自动列出安装目录、应用数据、快捷方式与注册表项，能删的和待确认的分开标注，逐条可勾选。

  3. 03

    确认清理

    默认送入回收站；占用中的文件先结束进程，仍失败的项目登记为重启后删除，结果一条不漏地列出来。

常见问题

你可能想先确认的几件事

还有别的问题，可以去 GitHub Issues 提，作者会看。

真的免费吗？会有广告或捆绑吗？

完全免费，没有广告、没有捆绑安装、不需要注册账号。安装包只有几 MB，卸载后不残留后台服务，也不会开机自启。

会不会误删我自己的文件？

清理默认送入回收站，删除前会硬性拦截盘符根目录、C:\Windows 与系统关键路径。启发式命中的注册表项和数据目录默认不勾选，并标注「待确认」，由你逐条决定。

为什么可以静默卸载？

优先使用软件自己登记的静默卸载命令；没有的话，按安装器类型自动补参数（MSI 用 msiexec /X /qn，NSIS 用 /S，Inno 用 /VERYSILENT）。卸载向导里可以取消勾选，回到厂商原生界面。

需要管理员权限吗？

浏览程序列表不需要。写入 HKLM 或删除受保护目录时，界面会提示「以管理员身份重启」，点一下即可，不用重新下载和安装。

会上传我的数据吗？自动更新怎么工作？

所有扫描与清理都在本机完成，不上传任何数据，也不需要登录。自动更新只会向 GitHub Releases 拉取更新清单与安装包，签名校验通过后才会安装。

支持哪些系统？

Windows 10 与 Windows 11（x64）。界面基于系统内置的 WebView2，Windows 11 已内置，Windows 10 首次安装时会自动补齐。
