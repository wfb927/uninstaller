# 卸载大师 · 官方下载与更新通道

轻量级 Windows 软件卸载与残留清理工具（Tauri 2 + Rust + React）。

> 本仓库只发布**安装包、更新清单与官网**，源码不公开。

## 下载

最新版：[Releases](https://github.com/wfb927/uninstaller/releases/latest)

| 系统 | 安装包 |
| --- | --- |
| Windows 10 / 11（64 位） | `Uninstaller_x64_<版本>_setup.exe` |

安装包为当前用户安装，无需管理员权限；需要清理系统级残留时可右键「以管理员身份运行」。

## 更新说明

应用内置自动更新：启动后自动检查，也可在「关于 → 检查更新」手动触发，更新源为本仓库的 Releases 清单。
